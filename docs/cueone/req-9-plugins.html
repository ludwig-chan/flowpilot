插件系统

提供 API 接口，支持第三方开发者扩展功能

需求 9

做什么

类似 uTools 的插件机制，提供开放接口供第三方开发者扩展功能。插件可注册到万能输入框，访问 cueOne 的核心能力（OCR、AI、文件系统等）。
详细要求
  • 插件 SDK：提供开发文档、示例代码、CLI 工具
  • 插件注册：插件可注册到万能输入框，作为可执行操作
  • API 访问：插件可调用 OCR、AI、文件系统、剪贴板等核心能力
  • 插件市场：内置插件浏览、安装、更新（待设计）
  • 本地安装：支持从本地文件安装插件
  • 权限管理：插件需声明所需权限，用户授权后使用
  • 插件管理：启用/禁用/卸载插件

需求 3：下载捕获

在流程设置中配置下载行为，流程执行时自动按配置处理下载文件。

需求 3

做什么

在流程设置中新增"下载处理"配置项，流程执行过程中如果触发下载，按配置自动处理，无需用户手动干预。
详细要求
  • 配置位置：流程设置（FlowSettingsModal）中新增"下载处理"选项
  • 三种模式
    • 忽略：不处理，按浏览器默认行为下载
    • 捕获为附件：拦截下载，保存到客户端，关联到当前数据记录
    • 保留并捕获：正常下载到浏览器默认目录，同时复制一份为附件关联数据记录
  • 触发场景：流程执行中页面触发下载（a 标签 download 属性或 JS 动态触发），支持所有文件类型
  • 附件存储：保存到客户端指定目录，关联数据记录，支持后续 OCR 处理
  • 无需弹窗：按流程配置自动执行，不打断流程运行

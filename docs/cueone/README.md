# cueOne — 产品需求

> 一个入口，无限可能。

---

## 产品定位

基于 FlowPilot 桌面端能力，开发一个超级效率工具。整合截图、OCR、AI、待办、日程、文件搜索等能力，通过两个入口统一访问。

类似 uTools + Snipaste + PixPin 的结合体，加上 AI 处理链路。

---

## 两个入口

### 入口 1：截图

截图 → OCR 识别文本 → AI 理解内容 → 自动执行

- 截图后自动 OCR
- AI 识别文本内容，自动判断意图（生成待办、日历、笔记等）
- 截图标注（Snipaste 风格）

### 入口 2：全局快捷键

按下快捷键 → 弹出万能输入框 → 执行操作

- 搜索本地文件（类似 Everything）
- 向 AI 提问
- 执行操作（待补充）

## 插件系统

类似 uTools 的插件机制，提供开放接口供第三方开发者扩展功能。

- 提供插件开发文档和 SDK
- 插件可注册到万能输入框，作为可执行的操作
- 插件可访问 cueOne 的核心能力（OCR、AI、文件系统等）
- 插件安装/卸载/管理界面

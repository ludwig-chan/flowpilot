需求 1：关键字筛选

在数据记录页面提供关键字筛选功能，帮助用户从大量采集数据中快速定位目标记录。

需求 1

做什么

在数据记录页面提供关键字筛选功能，帮助用户从大量采集数据中快速定位目标记录。
详细要求
  • 搜索范围：搜索文本 = 所有字段值 + 关联截图的 OCR 文本
  • 筛选规则
    • 包含关键字（白名单）：命中任一或全部才保留
    • 排除关键字（黑名单）：命中任一就排除
    • 匹配模式：任一匹配 / 全部匹配（针对白名单）
  • 时间筛选：支持时间范围筛选，快捷选项（今天、最近 7 天、最近 30 天、自定义）
  • 筛选预设：条件可保存为预设，支持编辑、删除

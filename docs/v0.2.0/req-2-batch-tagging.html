需求 2

做什么

筛选后，用户可全选或选择部分记录，点击"打标签"按钮，弹窗选择已有标签或输入新标签，批量打标。
详细要求
  • 操作流程：筛选 → 勾选记录 → 点击"打标签" → 选择/输入标签 → 确认
